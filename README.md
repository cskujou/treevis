# 树结构可视化工具

一个基于 Web 的通用树结构可视化工具，支持点击节点展开/收起子树。

## 特性

- 🌳 支持任意树结构（不仅是二叉树）
- 🖱️ 点击节点展开/收起子树
- 📄 基于 JSON 的树格式定义
- 📥 支持上传 JSON 或粘贴 JSON
- 🗂️ 文件列表支持手动排序、文件名排序、上传时间排序
- 🧲 手动排序模式支持拖拽调整顺序
- 🧭 支持文件列表切换与键盘左右键切换
- 🈳 数据列表可清空，空状态会提示用户上传或粘贴 JSON
- 🔍 支持缩放按钮（放大 / 缩小 / 重置）
- 🖱️ 支持可视化区域滚轮缩放（鼠标锚点缩放）
- ✋ 支持空格 + 鼠标拖拽平移视图（类似设计工具）
- 🎨 美观的渐变配色和动画效果
- ✨ 平滑的贝塞尔曲线连接节点

## 安装

需要 Python 3.13+ 和 [uv](https://docs.astral.sh/uv/):

```bash
uv sync
```

## 使用方法

### 启动服务器

```bash
uv run treevis
```

浏览器会自动打开 `http://127.0.0.1:8000`。


### 命令行参数

```
--host           绑定的主机地址 (默认: 127.0.0.1)
--port, -p       绑定的端口 (默认: 8000)
--no-browser     不自动打开浏览器
```

## 数据输入与列表管理

### 数据输入
- 上传模式：点击“点击选择 JSON 文件”或直接拖拽 `.json` 文件到页面
- 粘贴模式：切换到“粘贴JSON”，输入后点击“添加到列表”

### 文件列表
- 点击条目可切换当前树
- 点击条目右侧 `×` 可删除（默认树也可删除）
- 删除到空列表时，页面会显示“请上传或粘贴 JSON”的引导提示

### 排序方式
- 手动排序：可拖拽条目调整顺序
- 文件名排序：按名称自动排序
- 上传时间排序：按加入列表时间排序

排序切换后会尽量保持当前正在查看的条目不变。

## JSON 格式

树的 JSON 格式：节点作为键，子节点用列表表示。

```json
{
  "根节点": [
    {"子节点1": [
      {"孙节点1": []},
      {"孙节点2": []}
    ]},
    {"子节点2": []}
  ]
}
```

规则：
- 每个节点是一个键值对，键是节点名称，值是子节点列表
- 空列表 `[]` 表示叶节点（无子节点）

## 交互操作

| 操作 | 效果 |
|------|------|
| 点击节点 | 展开/收起子树 |
| 收起状态的节点 | 显示为粉红色，带有 `+` 标记 |
| 展开状态的节点 | 显示为蓝紫色渐变 |
| ← / → 键 | 切换上一个 / 下一个文件 |
| 鼠标滚轮（在可视化区域） | 缩放树图 |
| 空格 + 左键拖拽（在可视化区域） | 平移视图（上下/左右） |
